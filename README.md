# TargetLoad - 1RM Calc & Log

トレーニングの実績（重量・レップ数）から即座に推定1RMを計算し、目的に応じた次回推奨重量の提示・ワンタップ記録・インターバルタイマー起動までをシームレスに行える軽量ワークアウトトラッカーです。

---

## 主な機能

* **1RM & 目標重量の自動算出（Epley式）**
  * 入力した重量・回数から推定1RMを即座に計算。
  * 器具の刻み幅（ステップ値）に合わせ、目的に応じた推奨重量へ自動丸め込み：
    * **筋力重視 (5 reps)**
    * **筋肥大 (10 reps)**
    * **筋持久力 (15 reps)**
* **ワンタップ記録 & タイマー自動連動**
  * 推奨ボタンをタップするだけで実績を保存。
  * レップ数に応じたインターバルタイマーが自動始動（5回以下: 180秒 / 6〜14回: 120秒 / 15回以上: 90秒）。
  * タイマーの「+30秒」「スキップ」にも対応。
* **単位切り替え（kg / lb）**
  * kg / lb のワンタップ切り替え対応。
  * 器具の重量ステップや表示も単位ごとに自動適用。
* **種目カスタマイズ（全10枠）**
  * デフォルトでダンベル種目を中心とした10枠を用意。
  * ギアアイコンから種目名や器具の刻み幅を自由に編集・保存可能。
* **履歴表示 & 成長可視化グラフ**
  * 選択中種目・単位のログ一覧を表示。
  * Chart.js による推定1RMの推移グラフで成長を直感的に把握可能。
* **ローカルストレージ完結**
  * サーバー通信やユーザー登録は不要。データはすべてブラウザ（LocalStorage）に保存。

---

## 計算ロジック

本アプリでは推定1RMおよび目標重量の算出に **Epley式** を採用しています。

$$1\text{RM} = \text{Weight} \times \left(1 + \frac{\text{Reps}}{30}\right)$$

目標レップ数の重量逆算：

$$\text{Target Weight} = \frac{1\text{RM}}{1 + \frac{\text{Target Reps}}{30}}$$

※ 算出された目標重量は、設定した刻み幅（ダンベルやプレートの増分）に最も近い値へ四捨五入されます。

## 使い方

1. **ファイルを開く**: `index.html` をブラウザで開きます。
2. **種目・設定の調整**:
   * 右上の「⚙ 種目編集 / 単位」から単位（kg / lb）や器具の刻み幅、種目名をカスタマイズ。
3. **実績の入力**:
   * 前回の「重量」と「回数」を入力すると、下部に各ターゲットレップ数に応じた推奨重量が表示されます。
4. **セット実施と記録**:
   * 行ったセットのボタン（5回 / 10回 / 15回）をタップすると、ログが保存され、同時にレストタイマーが開始します。
5. **推移の確認**:
   * 画面下部で過去のログと1RM推移グラフを確認できます。
